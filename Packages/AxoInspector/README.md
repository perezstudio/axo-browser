# AxoInspector

All private Web Inspector API, behind runtime checks, with the public `isInspectable` route as a fallback.

Part of [Axo](../../CLAUDE.md), a native WebKit browser for macOS. See `docs/PLAN.md` for the architecture.

**Depends on:** AxoWeb
